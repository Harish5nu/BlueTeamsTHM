## 📌 Overview

A Security Operations Center (SOC) is a dedicated team responsible for **24/7 monitoring, detection, and response** to security threats. As a **Tier-1 (L1) SOC Analyst**, you act as the **first responder** for all alerts generated by security tools.

The main goal of a SOC is to keep **Detection and Response** effective using the right mix of **People, Process, and Technology**.

---

## 👤 Role of a SOC Analyst Level 1

As an L1 analyst, your daily responsibilities include:

* Monitoring alerts from:

  * SIEM
  * EDR / XDR
  * Firewall
  * Email Security
* Performing **alert triage**
* Identifying **True Positives vs False Positives**
* Escalating serious alerts to L2 / Incident Response
* Documenting everything in ticketing systems

### SOC Escalation Flow

```
L1 → L2 → L3 → Incident Response → Blue Team / Threat Hunters
```

---

## 🧱 SOC Structure & Roles

### SOC Levels

* **SOC Analyst L1:** First responder, basic triage
* **SOC Analyst L2:** Deep investigation & correlation
* **SOC Analyst L3:** Proactive threat hunting & IR support

### Other Key Roles

* **Security Engineer:** Deploys and configures security tools
* **Detection Engineer:** Builds and maintains detection rules
* **SOC Manager:** Manages SOC operations and reports to CISO
* **CIRT / CSIRT / CERT:** Handles major incidents beyond SOC scope

> Some organizations outsource SOC operations to an **MSSP (Managed Security Service Provider)**.

---

## 🚨 Alert Triage (Core L1 Skill)

Alert triage is the **foundation of SOC operations**.

### The 5 Ws of Alert Analysis

| Question | Example Answer              |
| -------- | --------------------------- |
| What?    | Malware detected on a host  |
| When?    | June 5, 2024 at 13:20       |
| Where?   | Host: GEORGE-PC             |
| Who?     | User: George                |
| Why?     | Downloaded pirated software |

### After Triage

* Confirm malicious activity
* Collect evidence (logs, screenshots)
* Create a detailed ticket
* Escalate to higher tiers if required

## 🛠️ SOC Technology Stack

Technology enables scalable detection and response.

### Key Security Solutions

#### SIEM (Security Information and Event Management)

* Collects logs from multiple sources
* Correlates events using detection rules
* Uses UEBA, Threat Intelligence & ML
* **Detection-focused tool**

#### EDR (Endpoint Detection & Response)

* Endpoint-level visibility
* Real-time & historical data
* Automated containment & response

#### Firewall

* Network traffic filtering
* Blocks unauthorized inbound/outbound traffic
* Detects suspicious network behavior

#### Other Common Tools

* Antivirus / EPP
* IDS / IPS
* XDR
* SOAR

> Tool selection depends on organizational size and threat surface.

## 🧑‍🤝‍🧑 Why Humans Are Targeted

Attackers target humans because they provide **direct access** to:

* Email accounts
* Internal systems
* Databases

These attacks rely on **Social Engineering**, exploiting psychology rather than technical flaws.

### Common Traits of Social Engineering

* Appears trustworthy
* Triggers emotions (fear, urgency, curiosity)

### Common Human-Focused Attacks

* Phishing
* Malware downloads
* Impersonation
* Deepfakes
* Keylogging & physical attacks

---

## 🛡️ Defending Humans

Defense consists of **Mitigation + Detection**.

### Mitigation

* Security awareness training
* Anti-phishing solutions
* Zero-trust mindset ("Trust but verify")

### Detection (SOC Role)

* Monitor alerts from email & endpoint tools
* Investigate suspicious user activity
* Automate response using SOC tooling

---

## ✅ Key Takeaways

* SOC L1 analysts are the **first line of defense**
* Alert triage and documentation are critical skills
* Logs, endpoints, and network tools work together
* Humans are often the weakest link — and the most targeted
* Strong SOCs rely on **People, Process, and Technology**
